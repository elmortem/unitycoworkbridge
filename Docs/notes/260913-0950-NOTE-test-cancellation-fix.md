# Исправление отмены тестов и восстановления очереди

Версии: Unity package 0.25.0, CLI 1.18.0, plugin 1.22.0.

## Изменённое поведение

- `cancel <TaskId>` обслуживается отдельно от обычной очереди. Ожидающая задача отменяется адресно; выполняющийся тест или кооперативный C#-скрипт получает запрос остановки. Действующее чужое согласованное окно защищено. Повторная отмена завершённого TaskId безвредна.
- Состояние и дедлайн теста переживают domain reload. Максимум одного запуска тестов — 300 секунд, включая весь выбранный набор; более короткие настройки и срок окна учитываются.
- До подтверждения остановки задача остаётся `canceling`. Для EditMode используется отмена Test Runner; для PlayMode выполняется выход из режима с восстановлением сцен. После 30 секунд без завершения диагностика показывает `cancel_blocked`.
- Терминальный результат не перезаписывается поздним callback. Отмена присоединённого запроса не останавливает общий прогон. Отмена самого прогона завершает его присоединённые запросы.
- Восстановление, оставшееся после завершённого владельца, автоматически заканчивается после проверки отсутствия живого исполнителя. Очередь не передаётся следующему писателю, пока исполнитель или восстановление ещё живы.
- `--wait` ограничивает всё ожидание клиента, включая очередь и ожидание служебного stopplay. Выход 2 сохраняет исходный TaskId. Статус показывает причину и начало блокировки; список очереди обновляется и во время восстановления.
- Ручные команды без сессии/токена разрешены и ждут чужого согласованного окна. Планировщик выбирает разрешённую задачу владельца окна, даже если перед ней ожидает ручная задача.

## Практические границы

Главный поток, заблокированный произвольным синхронным C#, не обработает команду отмены. Никаких внешних сервисов, убийства процессов или перезапуска Unity не добавлено. Отмена активных compile/UI/sceneshot через новую команду не реализована; они возвращают явный отказ, а ожидающие задачи этих видов можно снять.

Полная матрица выполнена на Unity 2022.3 / Test Framework 1.1.33. Публичный API CancelTestRun и совместимость диагностического чтения проверены по локальным исходникам более нового Test Framework WaterWalk; живой прогон в Unity 6.4 в эту проверку не входил.

Пакет/CLI/плагин обновлены в репозитории, ZIP готов. Установка в другие проекты и глобальные кэши плагинов не выполнялась.
